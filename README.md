
# Machine Learning Projects

A collection of machine learning projects exploring predictive modeling, feature engineering, and model evaluation across healthcare and tabular datasets.

## Projects

### 1. Heart Disease Prediction

**Dataset:** UCI Cleveland Heart Disease Dataset

Comparison of Naive Bayes and regression-based approaches for binary heart disease classification.

**Methods:**
- Missing data handling and exploratory analysis
- Feature transformation and interaction features
- Naive Bayes, Ridge, and Lasso
- Classification metrics and ROC analysis

### 2. Gradient Boosted Trees vs. Multi-Layer Perceptron

**Dataset:** Bank Marketing Dataset

Comparison of gradient-boosted trees and neural networks for predicting term deposit subscriptions.

**Methods:**
- Stratified training, validation, and test splits
- Leakage-aware preprocessing
- XGBoost with early stopping
- Multi-Layer Perceptron classification
- Hyperparameter selection using validation average precision
- Precision-recall analysis and log loss

## Tools

Python · pandas · NumPy · scikit-learn · XGBoost · Matplotlib · Seaborn

## Focus

These projects emphasize not only predictive performance but also the importance of preprocessing decisions, model selection, and reliable evaluation.
